# cyb v5: Zaid Hsaine's portfolio

A multi-page, 3D, interactive portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, **React Three Fiber** and **Motion**.

[Website](https://zaidhsaine.com) · [GitHub](https://github.com/hsainezaid0) · [Online CV](https://hsainezaid0.github.io/CV---RESUME/)

## Pages

| Address | What's on it |
|---|---|
| `/` | 3D network globe (servers, connections, packets, a scanning shield that catches threats), intro with a working terminal, links to every page, featured projects, contact call-to-action |
| `/about` | Story, key facts, photo in a tilting glass frame, the journey timeline with a path that draws itself, two case studies |
| `/skills` | What I can bring to a team (six 3D cards), skills grouped by area |
| `/projects` | Every project with its picture, animated filters, expandable previews. `/projects#snort` opens a project directly |
| `/contact` | Form, email with copy button, GitHub, CV, website, and an invitation for real feedback |

## On every page

- **Navigation**: a top bar with a sliding highlight on the current page. It tucks away when you scroll down and comes back when you scroll up, with a reading-progress line. On phones and tablets the pages sit in a **bottom tab bar**, within thumb reach.
- **Moving background**: circuit-board traces with pulses of light running along them, slow indigo light, a dotted grid, and a soft glow that follows the mouse.
- **Light/dark switch**: the new mode spreads in a circle from the button (View Transitions API); older browsers fade the colors.
- **Page transitions**: each page rises out of a blur when you arrive (`app/template.tsx`).
- Smooth scrolling (Lenis), FR/EN switch, Ctrl+K command palette, AI assistant (Groq).
- **Readable text**: the type scale is larger than Tailwind's default (body text 17px, nothing smaller than 13px), set in `app/globals.css`.

## Project pictures

Each project has an illustration in `public/projects/` (SVG, drawn in the site's palette). To use your own screenshot or photo instead, put the file in `public/projects/` and change `image` (and `imageAlt`, the description for screen readers) for that project in `content/profile.ts`.

## Run it

You need **Node.js 20.9 or newer**.

```sh
npm install
npm run dev        # http://localhost:3000
```

```sh
npm run typecheck  # TypeScript checks every file
npm run build      # production build (also type-checks)
npm start          # serve the production build locally
```

## Key techniques, and where to find them

- **Server vs client components**: `app/page.tsx` and `app/layout.tsx` run on the server; files starting with `"use client"` run in the browser because they use state, effects or animation.
- **3D in React**: `components/three/HeroScene.tsx` uses `<Canvas>`, `useFrame` (runs every frame) and drei's `<Float>`.
- **Loading 3D only when it can run**: `HeroSceneLoader.tsx` uses `next/dynamic` with `ssr: false`, checks WebGL, and pauses the scene when it's off screen.
- **Mouse tilt and spotlight**: `components/ui/TiltCard.tsx` turns pointer position into springy `rotateX`/`rotateY` with Motion.
- **Scroll-driven 3D**: `DepthSection` and `Parallax` in `components/ui/Reveal.tsx` map scroll progress to rotation, scale and position with `useScroll` + `useTransform`.
- **A path that draws itself**: `components/sections/Journey.tsx` measures the nodes, builds an SVG curve through them, and binds `pathLength` to the scroll.
- **Shared-element transition**: the project cover uses the same `layoutId` in the card and the preview, so Motion animates one into the other.
- **Theme without a flash**: a tiny script in `layout.tsx` sets `data-theme` before the page paints.

## Accessibility and performance

- Respects **reduced motion**: Motion stops movement, smooth scrolling turns off, and the 3D scene shows one still frame.
- Full keyboard use: skip link, visible focus, Escape closes menus and dialogs, focus stays inside the project preview, arrow keys in the palette and terminal.
- Screen readers: the 3D canvas is decorative (`aria-hidden`); all content exists as real text with proper headings and labels.
- Three.js loads in its own file after the page is interactive; the scene pauses off screen and uses fewer particles on phones.
- Fonts are served by `next/font` from your own domain.

## The AI assistant

Without a key, the assistant answers offline from the site's content. To use Groq:

1. Create a key at [console.groq.com](https://console.groq.com/keys).
2. Copy `.env.example` to `.env.local` and set `GROQ_API_KEY=...`.
3. Restart `npm run dev`.

On Vercel, add `GROQ_API_KEY` in **Project → Settings → Environment Variables**. If Groq retires the default model, set `GROQ_MODEL` to one from [Groq's model list](https://console.groq.com/docs/models).

## Deploy (Vercel)

This version has a server route (`/api/chat`), so it needs a host that runs Next.js. GitHub Pages only serves static files.

1. Push the project to GitHub, **including `package-lock.json`** (the CI workflow needs it).
2. On [vercel.com](https://vercel.com), choose **Add New → Project** and import the repository. Vercel detects Next.js automatically.
3. Add `GROQ_API_KEY` as an environment variable, then deploy.
4. In **Settings → Domains**, add `zaidhsaine.com` and follow the DNS instructions. Remove the old GitHub Pages DNS records for the domain.

`.github/workflows/ci.yml` type-checks and builds every push, so mistakes show up before they reach the live site.
